# ServiceSwift

A scalable web application architecture with a Next.js frontend and an Express.js backend.

## Project Structure

- `/frontend`: Next.js Web App
- `/backend`: Express.js API Server

## Getting Started

### Initial Setup
Run the following from the root directory:
```bash
npm run install:all
```

### Development
To run each part separately:

**Frontend**:
```bash
npm run dev:frontend
```

**Backend**:
```bash
npm run dev:backend
```

## Environment Variables

Copy the `.env.example` in both folders and fill in your details.
